# Resultados del modelo SARIMAX semanal

Esta carpeta contiene los resultados obtenidos mediante el modelo SARIMAX aplicado a la serie semanal del precio de la papa súper chola, considerando una estructura estacional e incorporando variables climáticas exógenas.

- `Resultados_SARIMAX_Semanal.xlsx`: métricas de evaluación, valores observados, predicciones y resultados consolidados.

- `sarimax_s_test.pdf`: representación gráfica de la evaluación del modelo en el conjunto de prueba.

- `Grafico_sarimax_s_hist_y_pred.pdf`: comparación entre la serie histórica y las predicciones del modelo.

- `Grafico_sarimax_s_solo_pred.pdf`: visualización de las predicciones generadas por el modelo.

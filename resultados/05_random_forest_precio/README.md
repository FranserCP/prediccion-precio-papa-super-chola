# Resultados del modelo Random Forest semanal sin clima

Esta carpeta contiene los resultados obtenidos mediante el modelo Random Forest aplicado a la serie semanal del precio de la papa súper chola, utilizando únicamente variables derivadas del historial del precio.

- `Resultados_RF_Semanal.xlsx`: métricas de evaluación, valores observados, predicciones y resultados consolidados.

- `rf_s_test.pdf`: representación gráfica de la evaluación del modelo en el conjunto de prueba.

- `Grafico_rf_s_hist_y_pred.pdf`: comparación entre la serie histórica y las predicciones del modelo.

- `Grafico_rf_s_solo_pred.pdf`: visualización de las predicciones generadas por el modelo.

- `Grafico_rf_s_importancia.pdf`: importancia de las variables predictoras utilizadas por el modelo.

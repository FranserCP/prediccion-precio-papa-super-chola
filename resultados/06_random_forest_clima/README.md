# Resultados del modelo Random Forest semanal con clima

Esta carpeta contiene los resultados obtenidos mediante el modelo Random Forest aplicado a la serie semanal del precio de la papa súper chola, incorporando variables derivadas del historial del precio y variables climáticas rezagadas.

- `Resultados_RF_Clima_Semanal.xlsx`: métricas de evaluación, valores observados, predicciones y resultados consolidados.

- `rf_clima_s_test.pdf`: representación gráfica de la evaluación del modelo en el conjunto de prueba.

- `Grafico_rf_clima_s_hist_y_pred.pdf`: comparación entre la serie histórica y las predicciones del modelo.

- `Grafico_rf_clima_s_solo_pred.pdf`: visualización de las predicciones generadas por el modelo.

- `Grafico_rf_clima_s_importancia.pdf`: importancia de las variables de precio y clima utilizadas por el modelo.

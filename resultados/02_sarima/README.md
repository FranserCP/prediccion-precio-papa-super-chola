# Resultados del modelo SARIMA semanal

Esta carpeta contiene los resultados obtenidos mediante el modelo SARIMA aplicado a la serie semanal del precio de la papa súper chola.

- `Resultados_SARIMA_Semanal.xlsx`: métricas de evaluación, valores observados, predicciones y resultados consolidados.

- `sarima_s_test.pdf`: representación gráfica de la evaluación del modelo en el conjunto de prueba.

- `Grafico_sarima_s_hist_y_pred.pdf`: comparación entre la serie histórica y las predicciones del modelo.

- `Grafico_sarima_s_solo_pred.pdf`: visualización de las predicciones generadas por el modelo.

# Modelo XGBoost semanal

Esta carpeta contiene el script en R del modelo XGBoost semanal basado únicamente en el historial del precio de la papa súper chola. Esta configuración obtuvo el mejor desempeño predictivo y fue seleccionada como modelo final de la investigación.

- `Modelo_XGBoost_Semanal.R`: código para la preparación de variables, ajuste de hiperparámetros, entrenamiento, evaluación, pronóstico y generación de resultados del modelo XGBoost semanal.
